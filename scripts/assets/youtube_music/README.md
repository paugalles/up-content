Place a copyright-free mp3 file in this folder (e.g., from the YouTube Audio Library). 
If an `.mp3` is found here, `gen_reels.py` will use it to generate a `reel_youtube.mp4` video specifically for YouTube without triggering copyright claims.
If this folder is empty, `gen_reels.py` will generate `reel_youtube.mp4` containing ONLY the voiceover (no background music).
